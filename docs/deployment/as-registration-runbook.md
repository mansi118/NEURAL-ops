# AS registration runbook — registering `nc-channels` against the PRODUCTION `matrix.neuraledge.in`

> **Scope.** The exact, ordered, reversible steps to register the `nc-channels` Application Service against
> the **existing** EC2 Synapse (`matrix.neuraledge.in`, Synapse 1.150.0, live since 2026-04-04). This is a
> **production homeserver that has served real traffic for months** — none of the "it's just dogfood" cushion.
> So: **backup first, additive edit second, restart third, rollback known before any of it.** Per
> `ADR-matrix-homeserver` — we register against this box, we do NOT build a Fargate Synapse.
>
> **Division of labor (ML's lean, correct):** the *agent produces this verified artifact + rollback*; **ML
> runs it on the box** (SSH via `aws-server` key from the allowed IP). The blast radius of a bad
> `homeserver.yaml` edit is a real outage, so human hands on the box, agent hands over the cold artifact.

## Two values still TBD (do not invent them)
- **`__AS_TOKEN__` / `__HS_TOKEN__`** — minted on the box at apply time: `openssl rand -hex 32` each.
  **Never committed anywhere.** They must match on both sides: this registration file AND the `nc-channels`
  service config (`AS_TOKEN`/`HS_TOKEN`).
- **`url`** (`http://__NC_CHANNELS_ENDPOINT__:8010`) — where Synapse PUTs AS transactions. **Depends on the
  cross-VPC placement decision** (still open): on-box localhost vs a spine-VPC endpoint reachable from Synapse.
  Fill it once placement is decided; the HS must be able to reach it.

## Everything else is LOCKED (verified this session)
- `server_name` = **`matrix.neuraledge.in`** — confirmed live from the homeserver's own `.well-known`
  (`{"m.server":"matrix.neuraledge.in:8448"}`) and federation (`Synapse 1.150.0`). NOT from any tfvars.
- Exclusive namespace regex = **`@neop_.*:matrix\.neuraledge\.in`** — matches `server_name` exactly (or the
  HS rejects puppet mxids with `M_EXCLUSIVE`). `sender_localpart` = `neos-bot` → `@neos-bot:matrix.neuraledge.in`.
- The registration passes `validate_registration_dict` (fail-closed) as generated by
  `nc_channels/registration.py`.

## The registration file (`/data/nc-channels.registration.yaml` — path per Step 1)
```yaml
id: neos-nc-channels-neuraledge
url: http://__NC_CHANNELS_ENDPOINT__:8010     # fill from placement decision
as_token: __AS_TOKEN__                         # openssl rand -hex 32, on the box
hs_token: __HS_TOKEN__                         # openssl rand -hex 32, on the box
sender_localpart: neos-bot
rate_limited: false
namespaces:
  users:
  - exclusive: true
    regex: '@neop_.*:matrix\.neuraledge\.in'
  aliases: []
  rooms: []
```

---

## Step 1 — DISCOVER how this box runs Synapse (read-only, before any change)
The box predates our TF; we don't yet know if Synapse is Docker, docker-compose, or systemd. Determine, on the box:
```sh
# which of these answers tells you the runtime + the homeserver.yaml path + the restart command:
docker ps --format '{{.Names}}\t{{.Image}}' | grep -i synapse       # docker/compose?
systemctl status matrix-synapse 2>/dev/null | head -5               # systemd?
sudo find / -name homeserver.yaml -not -path '*/node_modules/*' 2>/dev/null   # the config path
```
Record: **`HSYAML`** = the real `homeserver.yaml` path, **`RESTART`** = the restart command for this runtime
(e.g. `docker restart synapse` / `docker compose restart synapse` / `sudo systemctl restart matrix-synapse`),
and where the AS registration file should live (same `/data` volume as `homeserver.yaml`).

## Step 2 — BACKUP the working config (recovery is a known command, not a reconstruction)
```sh
sudo cp -a "$HSYAML" "${HSYAML}.bak.$(date -u +%Y%m%dT%H%M%SZ)"
BACKUP="${HSYAML}.bak.<the-timestamp-just-created>"     # note the exact name; rollback restores THIS
```

## Step 3 — CONFIRM server_name on the live config (read-only, before editing)
```sh
sudo grep -E '^\s*server_name:' "$HSYAML"      # MUST print: server_name: "matrix.neuraledge.in"
```
If it is anything else, **STOP** — the regex assumption is wrong and the ADR needs revisiting. (It won't be;
federation already confirmed it. This is the belt-and-suspenders read on the artifact every room inherits.)

## Step 4 — Mint tokens + write the registration file
```sh
AS_TOKEN=$(openssl rand -hex 32); HS_TOKEN=$(openssl rand -hex 32)   # keep these; nc-channels needs the same
# write the registration file (above) to /data with the real tokens + the placement url, then:
sudo grep -q '@neop_' /data/nc-channels.registration.yaml && echo "regex present ✓"
```

## Step 5 — ADDITIVE edit to `app_service_config_files` (append — do NOT clobber existing config)
The box has run for months; it may **already** have `app_service_config_files` with other registrations. This
edit **appends**, it does not replace.
```sh
# if the key exists: add our path as a NEW list item, leaving existing entries intact.
# if the key does NOT exist: add it as a new top-level key with our single entry.
# verify BEFORE restart that the YAML still parses and existing entries survived:
sudo python3 -c "import yaml,sys; d=yaml.safe_load(open('$HSYAML')); print(d.get('app_service_config_files'))"
```
Expected: the list now includes `/data/nc-channels.registration.yaml` **plus anything that was already there**.

## Step 6 — RESTART (the discovered command) and VERIFY
```sh
$RESTART
# Synapse healthy + the AS loaded (no M_EXCLUSIVE/token errors in logs):
docker logs --tail 50 synapse 2>&1 | grep -iE 'appservice|application service|error' || journalctl -u matrix-synapse -n 50
# and CRUCIALLY — existing traffic still works (we didn't break the months-old server):
curl -sk https://matrix.neuraledge.in/_matrix/client/versions -o /dev/null -w 'client API: %{http_code}\n'
curl -sk https://matrix.neuraledge.in/.well-known/matrix/server    # still matrix.neuraledge.in:8448
```

## Step 7 — ROLLBACK (know it BEFORE Step 5; one command, no improvisation)
If Synapse doesn't come up clean, or existing traffic breaks:
```sh
sudo cp -a "$BACKUP" "$HSYAML"    # restore the exact working config
$RESTART
# re-verify client API + .well-known return to the pre-change working state
```
The AS registration file itself is inert once `homeserver.yaml` no longer references it, so restoring the
backup fully reverts the change.

## Acceptance
- Synapse restarts healthy; `@neos-bot` + `@neop_*` become AS-controlled on `matrix.neuraledge.in`.
- **Existing federation + client traffic unaffected** (the months-old server still serves).
- `as_token`/`hs_token` recorded for the `nc-channels` service config (same pair, both sides).
- Rollback verified-in-principle before the edit.
